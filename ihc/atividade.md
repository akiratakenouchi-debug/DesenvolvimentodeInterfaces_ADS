# Análise de UX/UI — Site KaBuM!

## 1. Interface e Interação

Interface de fácil acesso para conhecedores, porém não tão intuitiva para pessoas sem conhecimento da área. Poderia deixar os ícones em primeiro plano, para facilitar a escolha do usuário — os ícones de seleção de elementos de compra ficam na parte inferior, fazendo com que o usuário se confunda ou não encontre a área de interesse.

## 2. Usabilidade

Fácil usabilidade, nada muito complexo. Simples de executar compras e escolher os itens desejados; método de pagamento e carrinho intuitivos.

## 3. Acessibilidade

Possui ferramenta de acessibilidade, ajudando pessoas com necessidades especiais.

## 4. Ergonomia

Está no meio-termo. Em certas páginas do site, torna-se um pouco visível a poluição visual — por exemplo, na home, muitos produtos com preços são expostos logo de cara, gerando certa confusão mental logo no início do site, onde deveria haver maior clareza para atrair o usuário. No entanto, em outras partes, as interfaces são mais *clean*, como carrinho, pagamento e descrição do produto, com pouca poluição visual e bem intuitivas.

## 5. Responsividade

É possível acessar de qualquer dispositivo eletrônico, tornando o site promissor, já que qualquer pessoa pode acessá-lo. Também possui aplicativo para quem preferir.

## 6. ISO

Não. A KaBuM! não está nas normas da ISO 9241, porém os dispositivos vendidos, sim.
